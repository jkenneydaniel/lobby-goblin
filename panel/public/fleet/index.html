    The game will save and stop. Its containers and network will be removed. Its data volume will be available in Storage for inspection, recovery or permanent deletion. Published snapshots will be kept.

    A PLACE FOR YOUR SERVERS

    Add a game host

    Your panel can run here or elsewhere. Choose how to connect the machine that will run your games.

    For x86-64 Linux hosts with root or passwordless sudo access. We install the agent and connect it for you. SSH is not needed afterwards.

    Use an IP address or hostname the panel can reach, including a private or VPN address. Pairing secures the persistent connection. Only the dedicated agent port needs to be reachable (24443 by default).

    Advanced options

    SSH login details are used for this setup attempt and are not saved.

    Install the agent on the game-host machine, then paste its address and one-time code here. A separate panel or account is not required.

    I need to install the agent

    Run this command on the game host, replacing host.example.com with an IP address or hostname the panel can reach. It downloads the matching release source; no manual extraction or Node installation is needed. Private and VPN addresses work too. Allow TCP 24443 from the panel, or choose another port with --agent-port. Pairing verifies the encrypted connection; ports 80 and 443 are not needed.

    On Windows, extract the matching release and use ./Install.ps1 --host-agent with the host options; omit the public bootstrap’s --version flag. Setup prints the code. If it expires, use --host-agent --pairing-code --directory lobby-goblin-host.

    Review host setup

    Compare the SSH fingerprint with your provider’s console or another trusted record.

    Setup creates a separate agent installation and its persistent encrypted connection. It does not import existing games or worlds. Games are created later on the selected host.

    Align agent with panel
